cqieスケジュール · CQIEコーススケジュール
Androidクラススケジュールクエリアプリ：公式ログインページを開く → OAuthトークンをキャプチャする → 学生事務へ直接接続して「私の」クラススケジュールを取得。
自前のサーバーやサードパーティのSDKは使用せず、データはあなたの電話と学事サーバー間のみで流れます。
| | |
|---|---|
| プラットフォーム | Android 7.0+(minSdk 26 / targetSdk 34) |
| データソース | 重庆工程学院学事 `njw.cqie.edu.cn`(公式OAuth2 + Bearer API) |
| モード | 学事へ直接接続 · 一台一台、一アカウント（他者が使用する場合 = その者が自分のアカウントでログイン） |
| プライバシー | 読み取り専用の個人スケジュール；このデバイスはトークンのみを保存（約7日間、自己維持の無声更新）、パスワードは保存されません |
機能
**公式ログイン**：アプリ内統一認証CASページを開き、アカウント/パスワード/認証コードを入力して自動的にOAuthを実行してトークンを取得；有効期限切れで無声更新、ログインページが表示されるのは失敗時のみ。
**週間スケジュール / 今日** ダブルビューで現在の授業週を自動的に定位し、今日の列をハイライト表示（週間スケジュール）；今日ページでは現在授業中 / 次の授業 / 終了 + 30秒自動更新
スケジュールは公式学事から自動的に12時間分取得
空欄をクリックして任意の科目/タスクを手動で記録（線引きカード、ローカル保存）
**オフラインでの即時アクセス**：現在の学期のクラススケジュールはローカルにキャッシュされるため、インターネット接続がない場合でも表示できます；インターネット接続がある場合、バックグラウンドで自動更新が行われます。
**モバイルで全てを一屏に**：狭いスクリーンでの週間スケジュール、適応型列幅、7日間を完全に埋める必要はありません（左右スワイプ不要）
**アカウントセンター**(トップバー 👤)：現在のアカウントを確認 / ローカルキャッシュをクリア / **ログアウト**(公式CASセッションも含めてログアウトし、ログインページに戻り、アカウントを切り替えるための「Go to Official Login Page」をクリックすることでSSOが無声で元のアカウントにログインさせない)
目次
android/    原生壳(Kotlin + WebView + OkHttp): 登录链、token 存储、JS 桥
prototype/  网页原型 = 唯一 UI 真源(H5 三件套, 复用于 APK 内嵌)
docs/       需求文档
打包APK
パッケージングスクリプトは`prototype/`からH5をアセットに同期し、その後Gradleでパッケージングします。
android\build_apk.bat
製品: `android/app/build/outputs/apk/release/app-release.apk`(R8最小化とリソース縮小が有効)
純粋なフロントエンドをデバッグするには`prototype/index.html`を編集；`prototype/server.py`はローカルデバッグ用のバックエンドプロキシであり、リポジトリにはコミットされません。
適合範囲
自分のアカウントのみにログインし、自分のスケジュールのみを読み取ります；他のアカウントを集約したり、バッチでスクレイピングしたりはしません。リポジトリにはアカウント/パスワード/トークンは含まれていません。
